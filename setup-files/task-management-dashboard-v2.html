Quick Start Guide

1Fill the Form

Enter task details. Every field has a hint showing what to enter with examples.

Example: Create "Vault Weekly Update" running Monday & Thursday at 9:33 AM

2Save Your Task

Click "Save Task & Generate Script"

You'll see a success message and task appears in the list.

3Run Automation

Open Terminal and run:

cd ~/ClaudeCowork/Tara-second-Brain/_aibos
claude run task-automation.claude

This auto-generates:

  • Task specifications
  • Calendar entries
  • Claude Code scripts
  • Status tracking
  • Index updates

4Test & Deploy

Run the test version (dry-run):

claude run /_aibos/claude-code-scripts/YOUR-TASK-ID-TEST.claude

Verify output then task is ready!
